# The proof: two commands with an unconditional, checkpointed effect, in
# the grammar the dispatcher accepts, then one level-up on the record
# screen. 0x5838A0 splits the submitted line at the first ':' and
# requires position >= 1; the text before the colon is obfuscated
# ((c+8)*2 per char, 0x5844E0) and strcmp'd against 0x8AF630 =
# obf("CTRLALTDELETE") — anything else, or no colon, prints "Nice try
# cheater!" (0x8AF700) and does nothing. Past the colon the command name
# before '(' is matched by the strcmp chain 0x583E60 (ADDGOLD at
# 0x8AF660, index 0x10) and the args after '(' go to 0x5840E0; 0x584420
# takes ADDGOLD and SETCURRENTXP as one numeric arg. Every char of
# CTRLALTDELETE:ADDGOLD(500) is typable in the box (letters, digits,
# shift+9 '(' and shift+0 ')', and shift+VK 0xBA ':' via the box's OEM
# key table at 0x8ABA3C). What failed before was the box's preload: the
# ini's [Lua Edit] String0 (the last submitted line, any session's) is
# preloaded at open, the typed command appended to it and the dispatcher
# rejected the concatenation. probe.py strips that section around the
# run, so the box opens empty.
# RETURN submits the line but does NOT close the console: the dispatch
# path (0x77C350 -> 0x77C3F7 call 0x5838A0 -> destructors -> 0x77C473)
# never touches the console-open flag at [screen+0xf37]; only the
# [box+0x8a6]!=0 branch at 0x77C0B6 writes it to 0, and that branch
# never dispatches. The box also keeps its text after the submit — and
# BACKSPACE past the end of the text is NOT harmless: launch 1
# (runs/20261026-195352) showed the surplus keys reaching the world
# screen, which summoned the Party Formation engine (frame 3150, the
# single_player screen, back to the world by 3330), and the second
# RETURN went to that screen instead of the console. So the second
# command goes through a close and reopen (one CTRL+TAB, wait, another
# CTRL+TAB), and its BACKSPACE run must match the kept line exactly:
# 32 for CTRLALTDELETE:SETCURRENTXP(2000).
# SETCURRENTXP goes first, on the fresh open whose empty box the
# ADDGOLD run of Task 45 already proved. XPLEVEL.2DA is identical for
# every class — level 2 at 1000, level 3 at 3000 — so 2000 gives the
# level-1 sorcerer exactly one level-up (the previous 4000 would grant
# two).
