# IEex_Render_Patch.lua — GL renderer enable pack: native OpenGL, FBO present path, GL-parity fixes

Staged input: `~/.local/share/iwd2r/wso/lua/IEex_Render_Patch.lua` (888 lines). Upstream baseline: `IEex_Render_Patch.upstream.lua` (315 lines, IEex upstream commit 60de54611b249d3bcca3f6522ef9db5e7ec27339). Fork commit 138495fde69b6092b7318fad462d571864e9d9b8, ref `opengl-hd-beta7`.

The whole file is one IIFE wrapped in `IEex_DisableCodeProtection()` … `IEex_EnableCodeProtection()`. Diffing fork against upstream: the fork is upstream plus **one large pure insertion** (upstream line 5 → fork lines 6–356: the entire GL-enablement block) plus **GL-conditional extensions** threaded through upstream's fog, sprite-interlace, container-highlight and wined3d-log sections, plus a **fork-appended tail** (CheckResults3d no-op + two perf-note comments). Everything else (dither fix, cnc-ddraw fullscreen hooks, `VISIBLE_DELAY`, software-fog paths) is upstream IEex content this fork also ships.

## Intent

1. Turn the game into a **native OpenGL renderer**: flip one ModRM byte in `CBaldurChitin`'s ctor so `m_cVideo.m_bIs3dAccelerated` comes out truthy and the engine takes every `Is3dAccelerated()` branch (`Initialize3d()`, 3D fog, 3D palettes) — the fork never links a renderer of its own; it reuses the game's existing GL paths.
2. **Borderless fullscreen**: `CVidInf::SetDisplayMode` is no-op'd (`mov al,1; ret`) so DirectDraw mode changes never happen. Host-gated: enabled on native Windows or when ini `Windowed=1`; on Wine the DLL skips it (alt-tab black-screen trap, per fork comment).
3. **FBO present path**: the SwapBuffers call in `WindowedFlip3d` is replaced by `IEex_Helper_PresentScaled` — the DLL blits its framebuffer object to the window, scaled; ini "Fill Screen" gates it DLL-side.
4. **Alt-tab without context teardown**: `CChitin::OnAltTab` is hooked to ask `IEex_Helper_OnAltTabIntercept` first; if it returns nonzero the stock "destroy 3D context on focus loss" teardown is skipped (`ret 8`).
5. Remove the **upper-refresh filter** in `CVidInf` (`ja` over the refresh-rate write → 2× nop) so monitors above 60 Hz work; the `CVideo::FPS` static (0x8BA318) only ever got raised during DirectDraw init.
6. **Quit prompt**: `AskCloseConfirmation`'s `jne` on `m_bFullscreen` is nop'd so the confirmation dialog always takes the windowed branch (under GL there is no exclusive fullscreen to dismiss).
7. **Loading-screen repaint**: `CCacheStatus::Update`'s `jge` skipping the background repaint is nop'd — with a single FBO the loading parchment needs an erase + redraw every pass.
8. **Background audio**: gated on ini "Run In Background" — four immediate dwords add `DSBCAPS_GLOBALFOCUS` to both `CSound` buffer factories (2D + 3D) and the Interplay music lib's `soundAllocate`, so sounds keep playing when focus is lost.
9. **BINK movies under GL**: `EngineActivated`'s `je` is flipped to `jmp` (always open BINK), `EngineDeactivated`'s cleanup `jne` is nop'd, the DD-overlay subtitle ctor is jumped over (it would dereference a null DD surface under GL — 0xC0000005 per fork comment; subtitles are instead drawn GL-natively by the DLL's `MovieDrawSubtitles`), and `RenderBinkFrame` is wholly replaced by `IEex_Helper_RenderBinkFrameGL` (a `__thiscall`→`__stdcall` marshal: push arg, push ecx, call, `ret 4`).
10. **GL-parity fixes**: per-sprite tint flag `0x20000` restored (`or ebx,0x20000` no longer skipped — lightmap/night/infravision-grey/fade tints apply per cell); `CVidPalette::RealizeResource3d` is wrapped with a maintained-original hook routing to `IEex_Helper_CVidPalette_RealizeResource3dGrey` because the GL realize path misses the 0x80000 desaturate (grey-out) bit.
11. **Save-BMP screenshots**: the `glReadBuffer` and `glReadPixels` calls in the fork's `PrintSurfaceToBmp` (our tree has no such function; see hooks table) are detoured to `IEex_Helper_ReadBufferForSave`/`IEex_Helper_ReadPixelsForSave` — the pixels live in the DLL's FBO, and Wine needs a `glGetTexImage` workaround (GL_INVALID_OPERATION).
12. **Fog of war moved after the object passes under GL** (`FogTexDrawLate`), with DLL solid/transparent renderers behind the `IEex_FogTypePtr` switch; **sprite interlace dropped unconditionally under GL** (the 50% checkerboard punch-through was a resolution-dependent software artifact; fork measured a Targos goblin [50,66,65] with vs [25,31,21] without); **`CLAMP_TO_EDGE` stubbed onto the three CVidCell draw paths** (no mip padding in atlas space); **ground piles stop dimming in 3D**.
13. **Container/door/trigger highlight rebuilt for GL**: colour override via `IEex_Extern_OverrideContainerHighlightColor`, translucent GL fills behind the software outlines (is3D-only sites), a translucent text backdrop where the game used to blit an opaque panel, and `PolyLine` (lightning bolt) wholly replaced by `IEex_Helper_LightningPolyLine3d`.
14. **Fullscreen-toggle hardening (cnc-ddraw pack, upstream content, installed unconditionally)**: five hooks let DLL/Lua veto or redirect the Alt-Enter path and force the options screen to think/request windowed mode; plus `VISIBLE_DELAY` 7→1 (AI/artificial delay ~400 ms → ~66.6 ms) and a dither-crash fix in `RenderSpriteEffect`.
15. `CVidMode::CheckResults3d` (fork-appended tail) is no-op'd to `mov eax,1; ret 4` — the fork measured it at ~0.5% self time.

## Data flow

- **Stateless installer.** The Lua runs once at patch time; every byte write, stub, and hook table is fixed. All runtime state (FBO, present scaling, alt-tab policy, BINK frames, fog texture, fill geometry) lives in the DLL behind the `IEex_Helper_*` exports.
- **Gating is read at install time**: `IEex_Vanilla`, the master `[Program Options] "3D Acceleration"` key (managed elsewhere by IEex_Gui_State from `[IEex Options] "Software Renderer"`), plus per-block re-reads: fog/highlight `is3D`, "Run In Background" (audio), "Windowed" + wine probe (borderless), "Fill Screen"/save-screenshot keys (checked DLL-side at runtime, not here). Toggling in-game requires DLL cooperation; the Lua cannot undo installed hooks.
- **The `is3D` / fog-type readers** are two tiny `WriteAssemblyAuto` cave stubs (`getFogTypePtr`, `callHook`/`fillBlock`/`backdropBlock` thunks) placed by `IEex_WriteAssemblyAuto`; `getFogTypePtr` brackets a read of the DLL's `IEex_FogTypePtr` global with `IEex_Helper_LockGlobal`/`IEex_Helper_UnlockGlobal` ("IEex_Options") — the fog switch is DLL-shared state, mutated by the fog console commands, and hooks read it per frame.
- **Per-frame Lua touchpoints** are only the five `IEex_Extern_*` callbacks invoked via `IEex_GenLuaCall` (`IEex_FlattenTable`, `IEex_LuaCallReturnType`): `IEex_Extern_CheckForceFullscreen`, `CheckSuppressToggleFullscreen`, `CheckOverrideOptionsScreenThinksGameIsFullScreen`, `CheckForceOptionsScreenToRequestWindowedMode`, `IEex_Extern_OverrideContainerHighlightColor` (returns the container-highlight RGB or −1 = keep), plus `IEex_Extern_AfterDirectDrawCreate` (from the upstream block this fork keeps: a `IEex_HookAfterCall` at 0x7952FB inside `CVideo::Initialize(HWND, BOOLEAN)`'s DirectDrawCreate call site, src/CVideo.cpp:197). Everything else is pure assembly stubs → DLL exports.
- **Frame graph after the pack**: engine draws objects with GL; DLL FBO accumulates; `WindowedFlip3d` presents via `IEex_Helper_PresentScaled`; fog is composited late (`FogTexDrawLate` + `RenderFoW`); alt-tab keeps the context; movies render through `RenderBinkFrameGL`; screenshots read back from the FBO.
