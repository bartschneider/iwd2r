NOTE: the original calls an empty CInfGame member (0x71E750, `ret 8`) with the portrait and the creature's sex before it fills the slot; omitted. NOTE: nGameTime and nChapter are not initialized in the original (a save whose GAM cannot be read takes the previous save's values, the first one stack garbage); ours starts them at 0. The GAM buffer is freed with bare free() as the original does.
