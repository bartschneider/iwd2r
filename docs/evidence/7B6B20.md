## Notes

The lock/unlock pair the two software blits share: `dwSize` 0x6C into the
blitter's destination DDSURFACEDESC (+0x06), `Lock(&theDestRect, &desc, 0x21,
NULL)` (DDSD_CAPS|DDSD_HEIGHT|DDSD_WIDTH), then the same for the source into
+0x72 with 0x11 (DDSD_CAPS|DDSD_LPSURFACE). A `DDERR_WASSTILLDRAWING` answer
calls the current video mode's `RestoreSurfaces` (vtable +0x100) and retries, as
does `DDERR_SURFACEBUSY`; a failed source lock unlocks the destination. On
success `+0xE2`/`+0xDE` take the two `lpSurface` values (destination and source
row pointers). The HRESULT mapping is the original's: E_OUTOFMEMORY stays,
E_INVALIDARG and DDERR_INVALIDOBJECT become DDERR_INVALIDPARAMS, everything else
DDERR_GENERIC (a shim constant this port adds).
