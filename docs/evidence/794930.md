# 0x794930 CTlkTable::OpenFile

## Disassembly reading

- 0x794996 `push $0x20` - the single flags argument for the open call:
  MFC modeRead (0x0000) | shareDenyWrite (0x0020). typeBinary is 0x8000
  and is not set; the fork body passes modeRead | shareDenyWrite |
  typeBinary (0x8020).
- 0x7949a3 `call *0x20(%edx)` - the open call itself (the preceding
  `call *0x18(%eax)` at 0x79498b is the path fetch), with the header
  read and the "TLK " memcmp following, as ours does.

## Notes

Ours matches the exe; the fork body's extra typeBinary flag changes
the argument the exe pushes at 0x794996.
