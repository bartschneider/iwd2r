## Notes

Ported from the disassembly (0x5C1350-0x5C1E20); Ghidra's decompilation loses the stack locals. The order of the calls is the original's:

1. A stack `CAIAction` with the inlined default constructor and m_actionID = the SHORT at 0x847834 (96, ACTION.IDS `Rest()`), and a `CAITrigger(0x93, 0)` (0x420DC0; 0x93 is not in TRIGGER.IDS).
2. `sub_5CADF0` on the game.
3. Without a session or as the host: `GetVariables()->FindKey(CHAPTER_GLOBAL)` (vtable +4) whose result is dropped (kept); `CBaldurMessage` 0x436500 (nHP, bRenting, 0) which returns at once without a session (not ported, ADR 0002).
4. Not renting: `CGameArea::CheckRestEncounter` 0x46FEA0 on `m_gameAreas[m_visibleArea]`; TRUE skips to the end (the `goto done` at 0x5C151E-0x5C1525). Ported with the function itself (docs/evidence/46FEA0.md, CGameArea.cpp): the roll, its rand() draws (0x46FEFD, 0x46FF19, 0x46FF7A and on) and the encounter's spawn now run as the original's, so an encounter interrupts the rest before the heal, the Rest action and the trigger.
5. With `m_bHealPartyOnRest` (0x8E7524): for each party member (through `g_pBaldurChitin->m_pObjectGame`, GetShare) that is not dead in its base stats (+0x5BC & 0x800), the missing points `m_maxHitPointsBase` (unsigned WORD +0x5C2) minus `m_hitPoints` (signed +0x5C0) add to the total; more than one missing clears the "none hurt" flag; `GetClassMaskLevel(0xC)` (cleric, druid) > 0 adds level * 19 + 5 to the rate, `GetClassMaskLevel(0xC0)` (paladin, ranger) > 9 adds level * 19 - 0x93. Without it the total is nHP.
6. With a positive rate the total is rounded up to whole multiples of the rate (`idiv`, signed).
7. Time and feedback (`FeedBack(7, t, TRUE)`) with t = `CRuleTables::TIME_RESTING` (0x8DF018) without healing, else when total > rate (signed `jg`): t = T * total * 100 / (rate * 100) + T with an unsigned `div` (computed twice, as the original does, once for `AddCurrentTime` and once for `FeedBack`); else T when nobody is hurt by more than a point, else 2T.
8. For each party member (through `this`): a `CGameEffectHeal` (0x18C bytes, `CGameEffect::CGameEffect` then vtable 0x84AD9C, m_effectID 0x11) with m_effectAmount 1000 when healing on rest, else the rounded total, in a `CMessageAddEffect` (vtable 0x8487CC); a `CMessageAddAction` (0x847B24) with the Rest action; a `CMessageSetTrigger` (0x847BB8) with the trigger.
9. A `CAIAction` assigned from an inlined `CAIAction(203, CPoint(35, 0), 0, -1)` (0x847908 is 203, ACTION.IDS `FadeFromColor()`; 0x847F84 is the DWORD 35) and `GetGroup()->GroupAction(CAIAction(NO_ACTION, CPoint(-1, -1), 0, -1), TRUE, &fade)` (0x51DE20 is the CPoint constructor).
10. End: not renting, the world screen is selected if it is not the active engine (assert line 0x47C0); renting sets the result TRUE. The client signal (`CBaldurMessage::SendSignal` with a session and not renting) is not ported. Then, if the world is still not the active engine, `CCacheStatus::dword_8D0BA8` = TRUE and the world is selected (assert line 0x4831; a renting client then calls 0x436C00, not ported). `m_cButtonArray.ResetState()` on the game.
