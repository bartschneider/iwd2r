## Notes
Fixed in the ui-misc round 4 fix round (the single-player-host audit). The
keymap loop of the default key case (the CINFGAME_KEYMAP_SIZE entries,
GetKeymap and GetKeymapFlag against the key and Ctrl) increments its index
in the original. Ours never moved it, so any key not bound at keymap index
0 spun forever and hung the game. The test presses VK_F13, bound nowhere,
on a thread and checks that the press returns; it fails on the old loop.
