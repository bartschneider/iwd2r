CGameEffectDamage::DisplayString (stream effects-save, M3 fix round 1): ours inherited the base CGameEffect::DisplayString (0x4A4BB0), which shows the effect's EFFTEXT.2DA line (14027 for 12) with the effect text option's bit 8. Ours is an empty override with a NOTE.
