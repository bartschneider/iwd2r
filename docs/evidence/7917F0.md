## Notes

- **The tokenizer.** The function copies `m_sCommandLine` (this+0xDC) at 0x79183A and consumes the
  copy; `m_sCommandLine` itself is written once, at the return, with the words it did not recognise,
  each prefixed by a space (0x7925BA-0x79262A). Each iteration trims the copy (`CString::TrimLeft`,
  all whitespace), takes the next space-delimited word (0x791869 `SpanExcluding(" ")`), drops it
  from the copy (`Right(len - word.len)`, 0x79189E) and matches it with `strcmp` — case-sensitive,
  exact word only, so `+name=Hero` and `+NAME` are ordinary words.
- **The value step** (0x79190F-0x7919F3 and its repeats): a value that starts with `"` is taken up
  to the next quote, and the closing quote is required (the second `cmp byte ptr [eax],0x22`); when
  it is missing the option is consumed but nothing is assigned. Otherwise the value is the next
  space-delimited word. The remainder is trimmed again only by the branch that wants a value.
- **The options** (the strings at 0x8BA188-0x8BA1D8, in this comparison order):
