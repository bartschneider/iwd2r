version 2.0 game-file party entry (0x180 bytes) into the 2.1 layout (0x220
bytes). Ours is a file-local `sub_5A79E0` in CInfGame.cpp: each Ghidra

indexes in 16-bit units; ours in bytes, so the offsets are doubled). Bytes the
original does not write stay as the caller's buffer had them (zeroed once
per Unmarshal).

party members; the original's own ICEWIND2.GAM has none.
