# 0x75A4B0 CGameSprite::Berserk

## Decompiled (Ghidra, driver bundle 0x75A4B0)

Countdown handler for the STATE_BERSERK effect. On every call it decrements a
counter first, unconditionally; then, while the berserk state is active and the
count has not run out, it either attacks the nearest creature of any type (25%
chance, `rand() % 100 < 0x19`) or attacks the nearest enemy of the sprite's AI
type, falling back to WAIT 6 when no enemy is found. Every path returns
0xffff (ACTION_DONE).
