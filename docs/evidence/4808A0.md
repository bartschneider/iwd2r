## Notes

The original stores heap pointers (the point arrays, and for a container the item array) in 32-bit fields of
the record, which CGameArea::Marshal reads back as pointers before writing
the area file. On a 64-bit build they did not fit (docs/64bit-cast-sites.md);
they now hold iwd2r::MarshalPtr handles (compat/marshal_ptr.h) that the
game-file writers resolve with UnmarshalPtr. On 32-bit targets the handle
table works the same way. Nothing else changed.
