## Notes

Ported from the disassembly (0x5C1160-0x5C1347). When the party rents a room (the second argument), each party member is sent a `CMessage101` (vtable 0x84D3D0, 0xE bytes, field_C = 0, field_D = 1), built through `CMessage::CMessage` with the member's id as caller and target.

Without a connection (`cNetwork.m_bConnectionEstablished`, g_pChitin+0x1032, clear) the call goes to `RestPartyPrivate` with both arguments and returns its result. A client (connected, not host) asks the server to start the rest through 0x436290 unless `m_cBaldurMessage.m_bInOnRestAnnounce` (chitin+0x488A) is set, in which case it rests locally; 0x436290 needs a remote server, so that send is not ported, but the branch still returns TRUE as the original does.

A host (connected, `m_bIsHost` set) starts the rest now or defers it: `SetPendingRest(nHP, bRenting, FALSE)` when the save game's mode is 386 or 1282 (dialog modes), the multiplayer settings' `m_bHostPermittedDialog` (game+0x1C58) is set, or the world screen's `m_bHardPaused` (engineWorld+0x146) is set; otherwise `StartRestMultiplayerHost(nHP, bRenting, CInfGame::m_bHealPartyOnRest)` (ds:0x8E7524). Both return TRUE. A single-player game is a connected host session, so this branch is what runs in single player (wave2-common.md, "Single player is a host session").
