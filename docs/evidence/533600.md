(sizeof 0x2A2, vtable 0x84E724) from the source cell's animation resref,
copies the inherited fields, registers each through virtual slot 0x88
(`AddVisualToArea` 0x533AE0), and recurses for `nCount` steps on two
directional points. The name is address-derived: its only exe caller
