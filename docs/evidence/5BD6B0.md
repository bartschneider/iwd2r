whose id is valid and, when a session is open (`cNetwork + 0x6E0`), whose
multiplayer status is CHARSTATUS_CHARACTER (0x84D5A3); a GetDeny failure
returns from the whole function. For each kept character: when hosting
(`cNetwork + 0x6E1`) the controlling player, status (SIGNAL_IMPORTED 0x84D5A8
if the old slot had a character, else SIGNAL_DELETED 0x84D5A9) and ready flag
move to the new slot; then `m_cGameStats.RecordJoinParty()` (sprite + 0x4BB6),
EnablePortrait and UpdatePortraitToolTip with GetNameRef.

order of characters still in the party, then the party members that had no
portrait, then -1 in both arrays for the unused slots (with the multiplayer
slot reset when hosting). When hosting it ends with
CBaldurMessage::SendFullSettingsToClients("").
