## Notes

Ported from the decompile and the disassembly at 0x7C1429 to 0x7C1480 (the cache object is 0xA09F20, the edge buffer 0xA07B20). Was a stub returning FALSE, so CInfinity::FXRenderClippingPolys (0x5CE350) drew no non-convex wall polygon: sprites behind those walls were not occluded.

The scanline fill of a polygon of any shape: the edge table (BuildEdgeTable, 0x7C1970) is built into the global edge buffer, or for a fill without 0x2 restored from the cache (0x7C1DE0, 0x7C1EC0) keyed by the vertex list's address and count. Rows run from the first edge's top y until both tables are empty; edges starting on a row move to the active list in x order (the inserted edge's x compared as a short), spans are drawn between pairs of active edges when the row lies in the clip (xMin from the left edge clamped to the clip's left, xMax from the right edge clamped to right - 1, both relative to the clip's left), then the active edges step (AdvanceActiveEdges, 0x7C18F0) and are bubble-sorted by x. The span function, the clip with right and bottom minus 1, the 0x8 flip (row offset from bottom - 1, negative pitch) and the reference point's y follow FillConvexPoly (0x7C0F40).

NOTE (bounded): with every edge horizontal the edge table is empty, and the original reads the first edge's y through NULL (0x7C147E). Ours returns TRUE without drawing, which is what the loop would do. The cache is keyed by address: a vertex list freed and a new one of the same count allocated at the same address takes the old table, in the original as in ours (docs/followups.md).

Oracle case vid/fill_poly compares the original with ours on the 64x48 canvas of random pixels of vid/fill_convex_poly: a notched square, an L, a U, a comb, a bow tie that crosses itself, a zigzag, a triangle and a rectangle, and random star-shaped polygons of 3 to 12 vertices, each solid, dithered, shaded, mirrored and flipped in three clips, every polygon filled twice so the second fill takes the cached table: 2784 inputs, 0 failures. The vertex lists sit at fresh addresses on both sides. tests/test_vid.cpp checks a notched square (whole, clipped, flipped, dithered) against spans walked by hand and the empty edge table.
