## Notes

`SoftBlt`'s keyed twin: the same lock/rect/mirror skeleton, with the source
surface's `DDCKEY_SRCBLT` colour key (its low word in both halves of the dword
the original compares) and the keyed row copies at 0x7B6DC0 (mirrored) and
0x7B6F20 (plain), so a source pixel equal to the key leaves the destination's
pixel untouched. Selected by `CVidBlitter::Init` at 16 bpp when
`m_bSoftSrcKeyBlt`/`m_bSoftSrcKeyBltFast` are on (iwd2r runs at 32 bpp, so it is
ported for the record). `tests/test_ddraw.cpp` pins the plain and the mirrored
keyed copies: the key pixel keeps the destination's marker.
