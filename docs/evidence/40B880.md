## Notes

Ported from the assembly (0x40B880-0x40CAC0): the named-creature lookup (area table, then the game's), the walk over the five special-case bytes with the jump tables at 0x40C9B8/0x40C934, Myself, LeaderOf, Player1-6, Protagonist, the script-object fields (ProtectedBy 0xEA, ProtectorOf 0x126, LastAttackerOf 0x6E, LastTargetedBy 0x162, LastCommandedBy 0xAE, LastHelp 0x1DA, LastTrigger 0x216, LastSeenBy 0x252, LastTalkedToBy 0x28E, LastHeardBy 0x2CA, LastMarkedObject 0x342, MyTarget 0x37E, SpellTarget 0x3BA; with the location check where the original makes it), Nothing and the default (the caller's type). The party picks (0x40BE85-0x40BF48, 0x40C3FD-0x40C46C): WeakestOf, StrongestOf, MostDamagedOf, LeastDamagedOf, StrongestOfMale, WorstAC and BestAC (specifiers 4-7, 28, 47, 48) set the type to ANYONE with the instance CInfGame 0x5BDFE0 picks for the SHORTs 1-7 at 0x851898-0x8518A4; no pick is NOONE and a return; otherwise the object held so far is released, the pick fetched as an AI object (0x40CB20), NOONE if gone, else its type and id. vis-probe round 8 ported the nearest families but the ordinals, from the assembly (jump table 0x40C934 by the byte table 0x40C9B8): NearestEnemyOf (0x40BF48) takes EVILCUTOFF (200) as the type when the current object's EA is at most GOODCUTOFF (30), GOODCUTOFF when it is at least EVILCUTOFF, and gives NOONE for a neutral one; the object is then fetched through 0x40CB20 with the back list (`push 1`), and when there is none a sprite caller whose own EA is at least EVILCUTOFF loses the base flag 0x10000 (0x40C892-0x40C8BA). Farthest (0x40C2B9) keeps the current type with the instance -1, FarthestEnemyOf (0x40C14E) takes the other side's as NearestEnemyOf; both ask CGameArea::GetNearest (0x46B160) in its farthest mode for a caller on the front list, else 0x46DAE0 from the caller's position, with the caller's visual range, terrain table, checkLOS and seeInvisible; the found id (or -1) becomes the instance and 0x40CB20 fetches it with the back list (0x40C7E2). NearestPC (0x40C46C) walks the portraits: alive (0x920 bit 0x800 clear), EA at most GOODCUTOFF, not the current object and visible to the caller (0x727B80 with the caller's GetCanSeeInvisible); the least squared distance to the caller's position, y not scaled, wins (strictly less); none is NOONE; the found type and id become the current type without fetching the object. NearestEnemySummoned (0x40C689) takes the other side of the caller's own EA, asks GetNearest (or 0x46DAE0) with its summoned-only argument 1, and a miss is NOONE. Later in round 8 the n-th nearest ordinals: SecondNearestEnemyOf-TenthNearestEnemyOf (29-37, 0x40C039) take the other side's type as NearestEnemyOf (a neutral one is NOONE) with n = ordinal - 28; Nearest (14) and SecondNearest-TenthNearest (38-46, 0x40C208) keep the current type with the instance -1 and n = ordinal - 37, Nearest included as 1 (0x40C208 subtracts 38, sets 0 for 14, then adds 1 at 0x40C231: Nearest is the second nearest, as SecondNearest). A caller on the front list asks 0x46BAD0 (caller id, type, visual range, terrain table, checkLOS 1, seeInvisible, 0, n, 0), any other 0x46DDC0 from the caller's position (..., 1, seeInvisible, n, 0); the common tail 0x40C7E2 as for Farthest.
