## Notes

Counts the stock of an item in a store (a bag's contents are a store named as the bag). In a session the store is demanded from the server first; without one (0x5C8448) the store is loaded by its resref (`CStore(const CResRef&)`, 0x54B150), its items walked (GetNumItems, GetItemId) and the stocks of those equal to the item added. vis-probe round 6: ours built an empty CStore without the resref on that path, so a bag never held anything single-player (FindItemBags, PartyHasItem, HasItem in a bag).
