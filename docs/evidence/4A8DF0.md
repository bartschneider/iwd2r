## Notes

CGameEffectDamage::sub_4A8DF0: the hit sound "H_" + damage group (BL_ crushing, PC_ piercing, SL_ slashing, ML_ missile) + material + digit, or "HIT_03A" for 0x8000000; other types play nothing. The material comes from the armour's animation code when its first character is 'A' (1 CL, 2 LR, 3 Ch, 4 PT, others nothing), else from the creature: animations 0x6403, 0xE62C, 0xF019 BN, personal space below 3 MS, up to 5 MM, else ML. The digit is rand() % N + '1' with N per group and material read from the jump tables 0x4A9A88, 0x4A9A98, 0x4A9AA8, 0x4A9AB8 and the idiv/and-mask sites (the and 0x80000003 form is signed % 4). The decompile loses the string arguments; the port follows the disassembly.

The sprite's last hit sound (+0x7102, vis-probe's CGameSprite::m_sLastHitSound): each case compares the name with it (strcmp) and, when equal, moves the digit on by one, wrapping to '1' after the case's last; the name with its digit is stored there (0x4A98A6); "HIT_03A" skips both. One draw per sound. tests/test_effects_save.cpp checks the same draw twice in a row gives the next digit.
