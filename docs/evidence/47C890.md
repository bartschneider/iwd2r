# 0x47C890 CGameContainer::CGameContainer

## Disassembly reading

- Non-null area: the exe calls AddToArea(pArea, m_ptWalkToUse, 0,
  LIST_BACK), stores FALSE to m_bDeleteMe, nulls the polygon-point member
  and zeroes field_8D2 - ours in the same order.
- Null area: the exe calls UtilAssert (0x780c00) with id 0x142 and the
  "pArea != NULL" string, then falls through to `delete this` - ours goes
  straight to `delete this`.

## Notes

The omitted assert is diagnostic-only on a contract-violation path: with a
null area the run terminates abnormally either way (the assert exits after
reporting; without it the delete-this path is reached just the same, since
ours does not dereference pArea). Ours' UTIL_ASSERT idiom elsewhere keeps
the `// __LINE__` comments in step with the exe's assert ids; here the
exe's assert sits on the null path ours does not instrument.
