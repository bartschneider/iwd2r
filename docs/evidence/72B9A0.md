## Notes

Ported whole from the decompile (CGameSprite's vtable 0x85BDD4, slot 0x8C). Until now sprites ran CGameAIBase::ProcessAI, so a sprite's effect list (ProcessEffectList 0x72DE60, called at 0x72DAC7) never ran in an AI update: after New Game reloads the party from the save, CDerivedStats::Reload copies the base skills and nothing applied HandleEffects' ability, racial and class skill modifiers (0x734550, sub_763E40). The world_entry replay showed it: the original's party[0].skills at world were 6, 7, 9, 12 = 1, 3, 1, 1 (Hide and Move Silently +1 for DEX 12, Intimidate 4 - 1 for CHA 9, Search -1 + 2 for an elf with INT 9), ours 7 = 4.
