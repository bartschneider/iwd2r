## Notes

New port from the disassembly (Ghidra merges the twelve CString slots).
`CItem::sub_4EA750(pText, rgbColor)`: who can use the item.

The unusable flags (header +0x1E, GetNotUsableBy inlined, assert 1879) and
the kit flags (GetNotUsableBy2 0x4E9CA0); with neither, or no active
engine, nothing. NOTE: a loop clears the flags' bits one by one and counts
nothing (0x4EA841-0x4EA84E); kept. The flags are read again.

Each entry is "  " + the TLK string + "\n" (0x8ABD08, 0x8A6A50). A set
bit lists the entry as not usable, a clear one as usable:
- if any of 0xE000: 31532 (0x4000), 31534 (0x8000), 31536 (0x2000);
- if any of 0x31000: 31533 (0x10000), 31534 (0x20000), 31535 (0x1000);
- if any of 0x3F800000: 31570 (0x800000), 31574 (0x1000000; NOTE: the
  only one that marks the item usable when clear), 31573 (0x2000000),
  31571 (0x4000000), 31569 (0x8000000), 31572 (0x10000000), 31576
  (0x20000000);
- always, the classes 34, 1083, 1079, 1080, 16799, 33, 1078, 1077, 1082
  (bits 0x1 to 0x100): a set bit adds to the not-usable list only while
  nothing has marked the item usable; 32 (0x200) the same, and when clear it
  marks the item usable;
- the kits 502, 504, 2012, 2022, 12786, 12785, 12787, 12788 (kit bits 0x40
  to 0x2000) and 9987: with flag 0x400 each clear kit bit is usable and
  marks the item usable, and 9987 joins the not-usable list when kit bit
  0x2000 is set and nothing is usable; without 0x400 each set kit bit is
  not usable and 9987 joins the usable list.

The heading, 31531 ("usable by") when something marked the item usable,
else 31530, goes through UpdateTextForceColor in `rgbColor`; then the
matching list through UpdateTextNoTrim "%s". The varargs CBaldurEngine
functions take the engine as their first argument in the original; ours
are static.

No rand. Tested with 00AX1H83 (0x4000 only), 00BARD01 (0x7FD, every kit
bit) and 00SWDL01 (no restriction) in tests/test_combat.cpp.
