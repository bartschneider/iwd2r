## Notes

New port (`CGameSprite::CheckIfUsedUp`, IEex's name). Called by
Swing after each blow with the slot and ability: the active engine's
UpdatePersonalItemStatus (vtable +0xEC), UNUSABLE for a bad slot or an
empty one (returns TRUE), and an item with charges left (or none to spend)
returns FALSE.

Combat stream, recovery session: the two TODO regions are ported from the
disassembly (Ghidra swaps the two parameters and merges the trigger
copies).

0x75D683-0x75D901, no such ability: for ability 0 the item is gone: the
EFF_M02 sound (0x8AA960) unless it stacks, Unequip (0x71B7A0) or, for the
selected slot, SelectWeaponAbility(fist, 0, 0, 1); ReleaseAll, delete, the
slot cleared; when it was the selected weapon, EquipMostDamagingMelee
without a launcher, else the launcher's best ammunition (0x75E330, melee
for a non-PC), and FALSE when that selected the same item again; TRUE
otherwise. For another ability: UNUSABLE with the item's name, ReleaseAll,
TRUE.

0x75D942-0x75DE3D, the charges spent (usage count 0 with a maximum): by the
ability's usage flags (+0x24), 1: the item vanishes as above (bRelease
cleared; IsPC decides the melee fallback) and the weapon set is chosen
again (0x726810, m_nWeaponSet); 2: Unequip unless selected, Release, and
the item becomes its used-up item (CItem::GetUsedUpItemId, SetResRef, the
name taken again) or is deleted without one; the same reselection; then
0x726810 for a party member not charmed (STATE_CHARMED, 0x2000) and TODO
0x75E150 (CGameSprite, not ported, outside this stream's grant) otherwise;
others keep the item. Then UNUSABLE with the name (the local trigger
reassigned), the item released when not yet, TRUE.

No rand of its own; the unequips recalculate the effects while the world
timer is stopped. tests/test_combat.cpp "CheckIfUsedUp keeps arrows" pins
ten draws for spent arrows (two ProcessEffectList runs).

vis-probe round 8: 0x75DAFA-0x75DB01, for a creature outside the party or charmed, calls EquipRanged (0x75E150, ported in round 8) and ignores its result; it was a TODO.
