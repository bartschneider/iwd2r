## Notes

control variable and time-of-day gates, the `<area><alias>_TIMER` and
`_DAY` game variables (created on the first run when missing), the
interval check, and ExecuteSpawn for every spawn of the list.

Original behaviour kept: the first run compares days scaled by
TIMESCALE_MSEC_PER_DAY (108000, read from 0x84EC10), later runs by the
folded constant 1296000 (twelve times that); both comparisons are unsigned.
GetGlobalVariable (0x4686C0) is the ai-dispatch stream's and still a stub
on this branch, so a spawn list with a control variable does nothing until
it lands. AR1000 has no spawn INI, so nothing here runs in walk_and_talk.
