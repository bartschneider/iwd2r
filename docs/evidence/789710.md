  the matching Leave later.
- Existing buffer: `if (pRes->m_pData != 0)` (CRes + 8), assert 0x1bb7 =
  source line 7095 with the "Attempting to free invalid resource." text,
  then the deallocator call, m_pData = 0 and field_DA -= *(pRes + 0x14)
  (pRes->nSize). The deallocator target 0x7fc984 is operator delete as a
  two-instruction forward onto free (0x7e9689) - ours' free(m_pData)
  is the same call.
- ReduceFreedList(1200000) at 0x78977c.
- Two drain loops over m_lServicedLow / m_lServicedMedium: the exe walks
  raw nodes from list heads at this + 0x0e and this + 0x2a (our header
  places the CObLists at 0x000a and 0x0026 with the head member at +4,
  so the same members), reads node data at +8, and for
  `pRes != NULL && pRes->field_40 == 0` calls the vtable + 0xc
  OnResourceFreed: nonzero -> Dump(pRes, 1, 0) + free(pRes) (direct CRT
  free 0x7e9689), zero -> Dump(pRes, 0, 0). Loop continues while
  field_DA > field_D6. Ours expresses the walk as GetHeadPosition/
  GetNext with the same guards and bodies.
- After Leave: `field_DA > field_D6 -> return FALSE`; then operator new
  (0x7fc95b - malloc plus the standard new-handler retry) sizes nSize,
  m_pData stored, field_DA += nSize, NULL check returns FALSE.
- `if (3 < nSize)` writes 0x59 0x75 0x6b 0x69 ("Yuki") at
  m_pData + nSize - 4; ours memcpy's the same four bytes under
  nSize >= 4. Return TRUE.
