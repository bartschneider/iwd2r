## Notes

Runs each world-screen update. While waiting for a response: scrolls the display to field_56 (the "journal updated" line), shows or hides the dialog button by the entry's m_bDisplayButton and the input mode, then for a marker other than -1 picks the reply (CGameDialogReply::Pick) or, for -2, ends: the next entry goes through Reload and CMessagePickedDialogResponse (to the new talker), no next entry through CMessageRemoveReplies and EndDialog(FALSE, TRUE). When not waiting but still in dialog mode (0x502), the dialog ends after six updates (m_dialogFreezeCounter), in multiplayer after six times ten; the multiplayer message the original builds there is never shown.
