## Notes

New port from the disassembly. The render flags are MIRROR_FX when the
animation mirrors (vtable +0x7C, IsMirroring; the inlined wrapper's assert
at ObjAnimation.h line 2101 is kept) or'ed with m_spriteEffectFlags.
Nothing is drawn without a duration. Dithering as in RenderSpriteCover.

While the splash cell (+0x5206) plays, only it is drawn: its frame
rectangle, FXPREP_COPYFROMBACK, positioned at the sprite with half the
effect reference's y subtracted, clipped through FXRenderClippingPolys and
blitted; the particles wait for the next frames.

After the splash, with particle arrays allocated: the FX rectangle is the
effect rectangle (m_rSpriteEffectFX, saved by StartSpriteEffect and
UpdateSpriteEffect) cut to the vid mode's FX size (vtable +0xD0,
GetFXSize); m_effectExtendDirection 1 extends it upwards (y offset
rect.bottom - fx height + 1), 2 cuts it to the FX height - 1, any other
value asserts (ObjCreature.cpp line 10799). The flags gain
FXPREP_COPYFROMBACK when the effect flags have 0x208, else
FXPREP_CLEARFILL | 1. Each live particle (index (base + random - 1) * row +
n, as a short; base is a signed byte; a 0xFFFF entry ends the row) sets
the effect cell's sequence (high byte) and frame (low byte) and is drawn
when it lies inside the rectangle with a quarter-frame margin and its
frame fits; a mirrored effect counts x from the right. When any particle
was drawn the clipping polygons and the blit follow.

NOTE: The original keeps the FX surface's size and each particle's frame
size in one variable; ours too.

No rand draws.
