## Notes

- Both appends push `0x8AB8A4` and call `0x7FCFAA` (`operator+=(const char*)`, which runs `lstrlenA`), so the source keeps the string literal `"\\"`, not `'\\'`; both are guarded by `cmp ..., 0x5c`.
- The only `0x3B` is `push 0x3b` at `0x7818E5`, the `Find(';')` argument - most likely why the decompiler printed `";"`. The literal dates from upstream 465b0c15 and was never edited since.
