## Notes

Filed by hand for the replay dump's `world` block (M2: doors, dialog,
party actions, explored tiles, creatures; oracle/replay/schema.json,
x-fields): `tools/gen_fields.py` takes these offsets from the `/* NNNN */`
comments of our headers, which `tools/check_evidence.py` does not check, and
the recorder reads them from the original's memory. This is a function that
reads the layout.

Ghidra names this body CAIObjectType::GetEnemyAlly (identical code
folding); the door's vtable slot 1 (0x8490B4, from `PTR_DeleteDoor_008490b0`
in CGameDoor's constructor, 0x485AC0) points here, so it is also
CGameObject::GetObjectType: it returns the byte at `this + 4`,
CGameObject::m_objectType. Field `object_type` (u8, 0x0004); the dump keeps
the objects whose type is TYPE_DOOR (0x21) or TYPE_SPRITE (0x31, the case
CGameArea::Marshal, 0x471630, sends to CGameSprite::Marshal). No header
changed.
