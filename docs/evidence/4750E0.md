The original stops the world timer when the world screen is NOT paused: `cmp byte [world+0x13E], bl` (bl is 0, set at 0x475105) then `jnz 0x475151` past the `call 0x54F9F0` (StopTime) at 0x475147; the decompile reads `if (*(char *)(world + 0x13e) == '\0') StopTime()`.
