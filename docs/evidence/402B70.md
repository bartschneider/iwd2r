## Notes

Pending: needs engine state. The case is registered with ORACLE_CASE_PENDING
and has no body.

The original parses the 2DA text only inside Load. It first sets the resource
(an inlined SetResRef calling CDimm::GetResObject 0x786DF0, then CRes::Request
0x77E610), and then calls CResText::Demand (0x7808E0) and CResText::Release
(0x780A40). Only after that does it parse inline, from about 0x402CBB. The
original has no routine that parses text without its resource manager, and
calling that manager is out of the oracle's scope (plan, Task 10). This
function is left to replays.

Ours was split for the oracle. The parsing half of Load is now
`C2DArray::LoadText(CString)`, unchanged line for line, and Load calls it
after Demand/GetText/Release. The oracle's table cases build our tables with
it. The original has no LoadText of its own, so there is no address.
