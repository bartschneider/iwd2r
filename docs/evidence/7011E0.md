## Notes

Ported from the decompile and the disassembly (0x7011E0-0x7028A0). A STR_RES on the stack; the channel from GetChannel (portrait + 7, or 13 for a non-party sprite); CanSpeak(soundID == SOUND_DYING, FALSE). Each sound id picks a speech entry of the creature (m_baseStats.m_speech, sprite + 0x648) with `rand() % count` over GetNumSounds(first, max) (an inlined helper that draws only for a non-zero count), fetches its string and sets the sound's channel; the ids that skip on their own: 5 (battle cry: the world screen's m_nBattleCryTimeOut for non-party sprites, the attack-sounds option and m_attackSoundDeadzone, set to 90; custom sounds from field_7360), 6 (custom sounds from field_737C into field_7410/field_7414), 9 (selection: the selection-sounds frequency option, `rand() % 5 == 0` at frequency 2, the rotating counters field_710A/C/E; custom sounds from field_73D0), 11 (select action: the command-sounds frequency option and m_firstActionSound), 14 (m_attackSoundDeadzone). Ghidra's switch labels give the speech offsets: 1 -> 0, 2 -> 7, 3 -> 9, 4 -> 11, 5 -> 2, 6 -> 33, 7 -> 36, 8 -> 13, 9 -> 15 or 29, 10 -> 15, 11 -> 22, 12 -> 29, 13 -> 38, 14 and 16 -> 40, 15 -> 44.

The common part (0x702071): the name colour; subtitles from the option at game + 0x43F6 (m_bSubtitles); with a secondary sound set (m_secondarySounds, 0x7252), the set's own string (CRuleTables::GetSpeechStringRef with the set name at 0x725A) when subtitles are on, and its sound (GetCustomSound; checked with CDimmKeyTable::FindKey when custom). A party member (EA_PC) plays the string's own sound; any other creature plays it through its voice sound at 0x4F2C, which this port declares (with the CSound at 0x4EC8 before it: the constructor builds five CSounds from 0x4E00 to 0x4F90, 0x6EFD10-0x6EFD6A), restarting it unless the same sound is still playing, positioned only when the string's sound has an area and the id is not one of 9, 10, 12. With showCircle, m_talkingCounter is the play time / 66, or 300. The text goes to the world screen with the name colour for both name and text.

NOTE (original bugs, bounded): the default branch asserts and then runs the common part with no string resource (ebp, the STR_RES pointer, is still 0 when the assert at 0x702065 returns into 0x702071), which faults; ours returns after the assert. In the non-party branch the "played" flag is an uninitialized stack byte (0xA3 off esp, read at 0x7027C9) when the sound has no resource or is already playing; it only decides m_talkingCounter with showCircle; ours takes it as FALSE.

Exemption: the function needs the TLK table, the resource manager, the sound mixer and the world screen of a running game, which the original cannot be given outside the game. Its rand() draws (ids 1-16, the selection frequency's `% 5`) are covered by the replay's ai_rng_state at every checkpoint after a click (GroupAction plays SOUND_SELECT_ACTION for the leader).
