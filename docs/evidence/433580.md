## Notes

Ported whole. `g_pChitin + 0x1032` is `cNetwork.m_bConnectionEstablished`
(cNetwork at 0x952, field 0x6E0): without it the answer is 0xFF. The host's
slot is `cNetwork.m_nHostPlayer` (0x952 + 0x78E). Deviation (NOTE in the
source): the original reads only its low byte, which makes its `== -1` test
dead, and a host of -1 (0xFF) would index past its eight-byte array and
corrupt the stack; ours reads the whole INT and maps -1 to 0. For a wait on SIGNAL_SERVER ('S') every
player but the host must have signalled; otherwise only the host must. The
queued signals (this + 0x28 size, 0x29 start, 0x2A end, 0x2B from, 0x43 type,
0x5B data) mark their senders. When everyone visible has signalled, the
signals are removed from the queue (RemoveSignalsFromQueue, 0x433310) and the
answer is TRUE; otherwise the first missing player's signal message is
fetched if one has arrived (the network receive path: under the null service
provider of ADR 0002 nothing arrives, so it is kept as written).

In single player the host is the only visible player, so SaveGame's hard
pause (CScreenWorld::CheckEndOfHardPause, 0x693680, waiting on SIGNAL_SERVER)
ends at once, as in the original.
