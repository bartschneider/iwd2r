# 0x714410 CGameSprite::InitQuickSpellData

## Disassembly reading

- The exe reads the spell's current count from the spells object at +0x8
  (ours' field_8) for each of the five class/level lookups and compares
  it against the button data being built.
- Feat gates go through `call 0x763150` three times (ours' sub_763150);
  the button gets +0x1D = usable byte, +0x1E = tooltip id, +0x10 = the
  description string id (with the -1 fallback to the spell name) and
  +0x18 = the tooltip description (ours' field_1D/field_1E/field_10/
  field_18).
- Ours performs the same lookups, gates and stores in the same order.
