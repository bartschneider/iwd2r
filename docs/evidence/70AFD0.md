## Notes

The original stores the heap pointer of the marshalled CRE in the area
creature record's 32-bit m_creatureOffset (+0x88, stored at 0x70B1D0
from the buffer Marshal 0x70B2F0 returned), and the game-file writers read it back as a
pointer before the save is written. On a 64-bit build the pointer does not
fit: ours stores iwd2r::MarshalPtr(creatureData) (compat/marshal_ptr.h) and
the writers resolve it with UnmarshalPtr (game-file stream). Nothing else
changed in this function.
