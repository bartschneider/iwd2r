# 0x713FE0 CGameSprite::GetSelectedWeaponButton

## Disassembly reading

- The exe presets the button: +0x18 = 0 (m_count), +0x1A = 2
  (m_abilityId.m_itemType), +0x1C = 10 (m_itemNum), +0x1E = 1
  (m_abilityNum), +0x2A = -1 (field_10, the description string id) -
  ours writes the same five presets.
- On a live item it demands the item, reads the ability, copies the
  name, then +0x1C/+0x1E take the selected weapon/ability pair, +0x2A
  gets GetItemAbilityDescription and falls back to GetGenericName on -1;
  +0x18 is re-zeroed and filled from GetUsageCount when the item stacks
  (GetMaxStackable > 1) - ours follows the same sequence including the
  -1 fallback.

(CButtonData.h, unowned). Every store address and fallback in the exe
