# 0x4EA3F0 CItem::GetMaxEffectSpellLevel

Highest spell level among the item's usable ability effects: walks the
item's abilities, requires the item res to be loaded (asserting on a zero
demand count at CItem.cpp:1478), skips zero abilities, and folds each
ability effect's `m_spellLevel` into an unsigned maximum.
