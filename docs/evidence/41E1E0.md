x-fields): `tools/gen_fields.py` takes these offsets from the `/* NNNN */`
comments of our headers, which `tools/check_evidence.py` does not check, and
the recorder reads them from the original's memory. This is a function that
reads the layout; the comments were already right, no header changed.

bodies, and ours labels the same address CGameObject::GetPos. Either way the
function returns `this + 6`, a reference to the CPoint at offset 6 of the
object: CGameObject::m_pos (`/* 0006 */ CPoint m_pos`, two LONGs x, y).
Field `sprite_pos` (i32 x 2, 0x0006 in CGameSprite, through CGameAIBase and
CGameObject; `tools/gen_fields.py` now follows base classes and reads a CPoint
as two i32).
