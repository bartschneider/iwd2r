## Notes

Ported from the Ghidra listing and the disassembly (0x5CD3C0-0x5CDA42, `ret 0x4`, `mov al, 1` at
0x5CDA3C): the mirror of `ScrollingRequestRect` (0x5D00C0). It reads the rect that function
remembered (`field_68/6C/70/74`) and the scroll state it stored (`field_196`), and cancels the same
cells instead of requesting them:

- the interior, one tile in from the remembered edges, with the starts clamped by `max(..., 0)` and
  the ends by `min(..., nTilesX/Y - 1)`, calls `CancelRequestTile(x, y, a1)`;
- the `field_196` switch (jump table at 0x5CD494, cases 1-8, default assert at line 0xa6d = 2669)
  cancels the one-tile border the remembered state entered: 1 row above; 2 row above + right
  column; 3 right column; 4 right column + row below; 5 row below; 6 left column + row below;
  7 left column; 8 row above + left column. The clamps per case are the same as the request
  function's and can be read in the source;
- unlike the request function it does not derive a flags byte or write anything: the remembered
  rect and state are left as they are, and it always returns TRUE (the request function's caller
  `CancelRequestRect` ignores the value; the port's declaration changed from `void` to `BOOL` to
  match the original's `mov al,1`).

The two functions call each other: `ScrollingRequestRect` starts with `CancelRequestRect(field_15E)`,
and `CancelRequestRect` calls `ScrollingCancelRequestRect(field_15E)` when `field_68 >= 0` and
`field_196` is nonzero, before cancelling the rect itself. Nothing in this function draws `rand()`.

## Oracle

`infinity/scrolling_cancel_request_rect` (oracle/cases/infinity.cpp) reuses the request case's
fixture: the same synthetic 8x8 WED, each cell's `WED_TILEDATA` naming its own tile as the secondary
tile (`wFlags` 2, `nSecondary` = cell index) with `bFlags` 0x02, so `CancelRequestTile` cancels the
cell's tile in both its secondary block and its trailing request (two decrements per visit), and the
same chitin/CDimm setup (`CDimm::CDimm` 0x781E60 and the runner's
`InitializeOriginalCriticalSection`; the counts stay well above zero, so `CDimm::CancelRequest`
only decrements them and never enters the lists or the critical section, but `g_pChitin` must still
be valid).

Every input randomizes the remembered rect (including outside the map), `field_196` (1-8) and `a1`
(0-255), and the tiles' pre-call counts (40-48, above the two decrements a single input can make).
It compares the WED image, the untouched rect/state fields and all 64 tiles' request count
(`field_44`) and `dwFlags`. The unit test pins each of the eight states' border cell by cell, the
interior, the remembered-rect/state handling, the clamps, the zero floor and an `a1` without bit 0.
