## Notes

The exe computes `m_nFrameExpected - 1` with the
`add eax,0xffff / and eax,0x8000ffff / dec+or+inc` sequence — the
compiler's materialization of `0 - 1` in 16 bits; the port's C
`m_nFrameExpected - 1` truncated by the `static_cast<BYTE>` stores is
the same arithmetic. The Send slot's return value is ignored by the exe
(EAX is reloaded immediately for the `LeaveCriticalSection` argument at
0x7a26d9), which is why the port's empty critical section is
observably equivalent for every store that follows.
