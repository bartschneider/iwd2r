## Notes

Calling convention (objdump): `__thiscall`, `ret 4` at 0x4034C5 and 0x403524,
returns LONG in eax. It takes `const CPoint&`.

The original converts with ToNumber (0x7E7B03), which is VC6's `atol`. It
skips spaces (0x09-0x0D and 0x20), takes one optional '+' or '-', then
accumulates decimal digits in 32 bits with no overflow check (`lea ebx,
[esi+eax*2-0x30]`), and negates for '-'. Our port called the C library's
`atol`, which saturates at LONG_MAX/LONG_MIN on Windows (UCRT) and is 64-bit
on Linux.

Oracle case `tables/getatlong` (oracle/cases/tables.cpp), on the fixtures
described in 403340.md. The inputs are every point one step around each table,
the 16- and 32-bit extremes on either axis, and 10,000 random points within
three of the table's edges.

First run (20261012-225211, seed 1): FAILED, 40,862 inputs, 341 failures, all
on the "signed" table's overflowing cells, for example:

      original -2147483648, ours 2147483647

with its wrap-around. The default path's copy of `m_default` is kept, as the
original makes it too (GetDefault, 0x403530). After the fix: run
