# 0x49FC40 IcewindCGameEffectSummon::UsesDice

The class's slot-7 (`+0x1C`) override of `CGameEffect::UsesDice`. The exe
body is six bytes: `mov eax, 1; ret` (the class is treated as using dice so
the effect's dice fields drive its amount). The same bytes are ICF-folded
into dozens of unrelated TRUE-returning methods, which is why the address
carries Ghidra's `CBaldurChitin::GetIDSChoosePixelFormat` name.

Callees: none. Callers: virtual dispatch only (slot +0x1C).

Tests: `[effects][vtable]` pins the slot; `[effects][data]` decodes effect 67
and checks `UsesDice() == TRUE`.
