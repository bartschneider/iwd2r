## Notes

Ours adds one line at the top of the body, the render API dispatch guard (src/render/api.h): with a backend installed it calls Backend::DrawPolyLine (lpPoints, nCount, rgbColor, nThickness; clip rSurface); CInfinity::RenderLightning is not guarded so its rand() calls still run and returns when the backend handled it; with none, the classic renderer, render::Active() is null, the guard falls through and the rest of the body is the decompiled one, unchanged.

Task 5 of the render API plan (stub ports) changed the 32-bpp body to the original's: the DDSURFACEDESC's dwSize is set before LockSurface (the original stores 0x6C), the lock's result is what the function returns when no segment is drawn (nCount below 2; ours returned an uninitialized value), and the pitch passed to the segment functions is lPitch >> 2 (sar) rather than lPitch / 4. The 16- and 24-bpp branches stay unported. DrawThickLine32 (0x7CBE70), which the thick segments call, is ported and has the oracle case vid/thick_line32.
