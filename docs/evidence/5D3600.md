# 0x5D3600 CScreenChapter::TimerAsynchronousUpdate

## Why ours was kept

The batch row flags WillScarlettOhara's fork (iwd2-re@e8dd16a750966af53f24daaf49dcb4fb13594c13,
read through git plumbing) as changed against our base body. Diffing his body
against ours shows the only differences are a single member rename: he reads ``m_pTextControl->m_nVisibleLines`` where we read ``m_pTextControl->field_A6A``..

``m_nVisibleLines`` does not exist in our CUIControlTextDisplay header;
both name the visible-line count at +0xA6A.

## The exe reading

Bundle decompile: the scroll-end test reads
``*(short *)(in_ECX[0x71] + 0xa6a)`` off the text control pointer - the same
field our body reads as ``field_A6A``.

Ours already matches the exe; adopting his naming would need header edits
outside this batch's owned files. Kept as ours.
