# 0x78A2F0 CResFile::OpenFile

## Reading

The exe resolves the BIF name through the alias list, opens the file, reads the
header/variable-entry tables, sets `m_bOpen`, and after the open flags the
dword at CResFile+0x38 when the resolved name's first two characters are `cd`.
Ours expresses the same sequence and the same cd-prefix flag (`field_38`).

His fork diff for this function is a rename only (`field_38` -> `m_bFromCD`,
plus `field_20` -> `m_pFileBuffer`); the body logic is unchanged, so the row
hinges on ours, which reads the same stores as the exe.
