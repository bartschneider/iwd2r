## Notes

Ported from the decompile and the disassembly at 0x7977D0; was a stub returning FALSE. CVidInf::FXRender's point form (0x79D450), which the particles (rain, snow, sparks) draw through, reached it, so no particle was drawn. The colour comes from ReduceColor (vtable 0x118, the rgbColor argument). For 16, 24 and 32 bpp, each point (surface coordinates, lPitch in bytes) is written as a word, three bytes or a DWORD; unless bClipped, only the points rSurface contains (PtInRect). Another depth returns FALSE, else TRUE. tests/test_vid.cpp draw_points32 checks a clipped and an unclipped draw by hand.
