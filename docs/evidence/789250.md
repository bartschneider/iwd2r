## Notes

`CDimm::WriteResourceWithData(const CString& sDirName, CRes* pRes, LPVOID lpBuf, DWORD dwSize)`.
The base name comes from the 8-byte resref: the original copies `pRes->GetResRef()` into a stack `CResRef` (`local_1c`) and assigns its address to `sBaseName` through `CString::operator=(LPCTSTR)` (0x7FCD57), which reads to the first zero byte. For an 8-character resref such as WORLDMAP that zero lies past the resref, in whatever MSVC placed next on the stack. Ours uses `CResRef::GetResRefStr` (0x78AA30, `"%.*s"` with 8), the exact 8 bytes: with clang the bytes after the local were not zero and the file was written as `WORLDMAP8.??.WMP` in the wrong folder (tests/test_save_load.cpp, the WMP round trip). The rest is the original's: `FindDirectoryInDirectoryList`/`AddToDirectoryList` on `sDirName`, the id from the directory index, `TranslateType` for the extension, `WriteFile`, then the key-table entry's id update with the `Dump` on no demands.
