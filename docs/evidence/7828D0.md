## Notes

The port is still a stub that returns 0, which GetResFileName (0x786520)
takes as the player's cancel of the CD request and answers with
exit(EXIT_SUCCESS). The original asks for the disc with MessageBoxA (callee
above) and reads the volume label (GetVolumeInformationA). The stub now says
on stderr which file and drive mask it was asked for, so a missing CD folder
is visible instead of a silent exit code 0 (the Windows Sandbox quit at the
world, task p3/winquit: compat/win_types.h's _chdir did not re-root the
[Alias] paths on MSVC). Behaviour is unchanged.
