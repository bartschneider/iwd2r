- `0x5a9db1 mov $0x3,%ebp; 0x5a9db6 push %ebp` - default 3;

Guard 1 (0x5a9d89..0x5a9d9f), as the exe executes it:

```
5a9d89: cmp    %ebx,%eax          ; ebx = 1 (set at 0x5a9be9 mov $0x1,%ebx)
5a9d8b: mov    %eax,0x43fa(%esi)  ; store the read value
5a9d91: jb     0x5a9d98           ; eax < 1 unsigned  ->  == 0  -> store 5
5a9d93: cmp    $0x5,%eax
5a9d96: jbe    0x5a9da2           ; eax <= 5 -> keep
5a9d98: movl   $0x5,0x43fa(%esi)  ; else (== 0 or > 5) -> 5
```

`ebx` is the shared default of the boolean options (`0x5a9bee push %ebx`
before "Duplicate Floating Text" 0x8b117c, "Translucent Blts" 0x8b1168, ...),
so the `jb` is an unsigned `== 0` test, not a general `<` clamp. The guard is
`v == 0 || v > 5 -> 5`.

Guard 2 (0x5a9dc3..0x5a9dd8) is the same shape with 3: `cmp %ebx,%eax` /
`jb` -> `mov %ebp,0x43fe(%esi)` (ebp = 3), `cmp $0x5,%eax` / `jbe` keep, else
store 3. The guard is `v == 0 || v > 5 -> 3`.
