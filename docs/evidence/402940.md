# 0x402940 CResBinary::Demand

Binary resource demand: besides the base `CRes::Demand`, the first
successful demand latches the version string at data+4 into
`m_resVersion` and marks the resource parsed; later demands while the
resource stays referenced (demand count > 1) skip the reparse.
