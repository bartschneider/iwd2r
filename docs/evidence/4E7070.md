## Body and original defect

The exe sets the loop counter to **nine** (0x4E707C: `mov edi, 9`) and copies
eight bytes per iteration from the source to the destination: entries 0..8 are
copied and the tenth entry is never touched, so the destination keeps
whatever it already held (zero when freshly constructed). This is the
original's behaviour and is kept as is; the test pins it by pre-setting the
destination's tenth entry and checking that it survives the copy.
