# Pre-work improvements — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the six gaps found this week before our own recovery waves start: decompiles in the bundles, no history rewrites by workers, Will's tip re-compared automatically, two workers per pool with a faster gate, the pending scenarios recorded. (Typed hook tables are the Frida plan's Task 5.)

**Architecture:** Five independent tasks on their own branches off `first`, merged in the order they finish; each is tool code plus tests, except Task 5 which is capture work. Nothing touches `src/`.

**Tech Stack:** Python 3 standard library; Ghidra headless (`tools/ghidra/make_project.py`); bash (`tools/gates.sh`, the `claude-glm` wrapper); CMake presets; the oracle replay tooling.

**Spec:** `docs/superpowers/specs/2026-10-23-pre-work-design.md`.

## Global Constraints

- Never push. Work only in the worktree named in the dispatch. Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- `src/`, `docs/wso/wave-state.json`, `docs/wso/import-state.json` are never modified by a task; the wave state's schema change in Task 3 is exercised on fixtures and applied to the live file only by the controller.
- No desktop windows: never set `IWD2R_DESKTOP_OK`, never `--host`. Sandbox only through the tooling, 2 launches per attempt with real `--new-attempt` reasons.
- Heavy Linux work (Ghidra, builds, tests) under `systemd-run --user --scope -q -p MemoryMax=8G -p MemorySwapMax=0 --`; one headless Ghidra at a time (the tooling's lock).
- Tool tests: `python3 -I tests/test_tools.py` must pass (696 at the base of this branch; each task adds its own).
- Another driver may be fast-forwarding `first` and working in `p3-wso-b0NN` worktrees: never touch those or `first`.
- Exports stay outside the repo under `${IWD2R_HOME:-~/.local/share/iwd2r}/ghidra-exports/`.

## Review Focus

- The decompile export must resume: a chunk that already has its files is skipped, so a crash after hours loses one chunk, not the run. Test in Task 1.
- The `history` transcript kind must not refuse `git checkout -b` (a new branch) or `git checkout <branch>`; it refuses `checkout --`/`checkout <tracked path>`. Test in Task 2.
- `recompare` must never touch a decided row or a row in an assigned batch; its new rows carry the new pin and old batches keep theirs. Test in Task 3.
- MAP.md regenerated at close on the merged tree must equal what two sequential batches would have produced. Test in Task 4.
- A scenario promoted from pending must match at every checkpoint on both sides; a partial match is not promoted. Task 5 reports per scenario.
